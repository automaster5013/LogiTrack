# 9주 실행 로드맵

| 주 | 결과물 | 완료 조건 |
|---|---|---|
| 1 | 요구사항, ADR, 모노레포, Compose | 서비스 health와 기본 테스트 통과 |
| 2 | 배송 생성/조회, 멱등성, PostgreSQL | 중복 요청이 동일 배송을 반환 |
| 3 | Kafka 이벤트, Python 시뮬레이터, 최신 위치 | 배송 생성 후 위치가 자동 갱신 |
| 4 | SSE, Next.js 관제 화면, Redis | 브라우저 재접속 및 실시간 표시 검증 |
| 5 | retry/DLQ, 메트릭, smoke test | 잘못된 메시지 격리 및 정상 흐름 유지(MVP) |
| 6 | 주문/창고/재고 ledger 서비스 경계 | 입고→피킹→출고 상태 전이 검증 |
| 7 | 경로/ETA/지연·이탈 분석 | 시나리오별 탐지 정확도 테스트 |
| 8 | outbox, tracing, replay, 장애 주입 | 유실 없는 복구와 trace 연결 증명 |
| 9 | KPI 보고서, 부하 시험, 데모/클라우드 계획 | 성공 기준 보고서와 포트폴리오 영상/문서 |

클라우드 검증은 9주차에 사용자 승인과 비용 상한을 받은 뒤 별도 환경에서만 수행한다. 그 전까지 AWS 자원을 생성, 재가동, 변경하지 않는다.
