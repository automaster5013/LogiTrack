# Windows 로컬 프로젝트 E 드라이브 이전 결과 — 2026-10-30

사용자 요청으로 Windows 로컬 LogiTrack 프로젝트를 C에서 E 기반 NTFS 저장소로 이전했다. 이 기록은 로컬 파일 이전·원본 보관·공유 Docker 자산 보존 결과이며, LogiTrack의 서비스 기동이나 공개 서비스 배포 검증을 의미하지 않는다.

## 저장 구조

| 용도 | 최종 위치 |
| --- | --- |
| 활성 프로젝트 | `T:\LogiTrack` |
| 물리 저장 파일 | `E:\AgentTrust\AgentTrust.vhdx`의 기존 NTFS T 드라이브 |
| 기존 경로 호환 | `C:\LogiTrack` junction → `T:\LogiTrack` |
| 원본 보관본 | 같은 E 기반 T 드라이브의 비공개 이전 기록 폴더에 `c-original-backup-20261030-035740`으로 보존 |
| Docker 이미지·볼륨 | 이미 E 기반 R 드라이브에 있던 기존 공유 Docker 저장소 유지 |

새 가상디스크나 포트를 만들지 않았고 Docker Desktop·서비스를 재시작하지 않았다. 기존 R·T 자동 연결 작업은 변경하지 않았다. T 자동 연결은 앞선 AgentTrust 실제 재부팅 검사에서 확인된 기존 설정을 이용하며, 이번 LogiTrack 이전 후 별도의 재부팅·LogiTrack 기동 검사는 수행하지 않았다.

## 검증 및 C 원본 정리

1. C 원본을 T의 활성 프로젝트로 복사하고 전체 파일의 SHA-256, 파일 목록·크기·수정 시각·속성, 대체 데이터 스트림, NTFS 소유자·그룹·DACL·SACL을 검증했다. 목적지 루트는 새 부모에서 추가 권한을 상속하지 않도록 봉인했다.
2. C 원본 디렉터리를 백업 이름으로 전환하고 기존 경로에 junction을 만들었다.
3. C 백업을 E의 원본 보관본으로 복사한 뒤, 원본 manifest를 기준으로 C 백업·T 활성 프로젝트·E 원본 보관본의 내용과 권한을 다시 검증했다.
4. 검증 통과 후 정확히 지정한 C 백업만 삭제했다. 삭제 후 연결 경로와 E 보관본, 공유 Docker 자산·서비스 상태를 다시 확인했다.

정리 완료 기록 시각은 **2026-10-30 04:13:16.517 KST**다. C 여유 공간은 정리 전 115,991,609,344바이트에서 정리 후 120,619,593,728바이트로 약 **4.63GB 증가**했다. 논리 크기와 실제 회수 공간은 NTFS 압축·할당 방식 등의 영향으로 다르며, 여유 공간은 측정 시점에 따라 변한다.

## 유지할 결정과 공개 범위

- LogiTrack은 계속 정지 상태로 유지한다. 이번 문서 업데이트로 컨테이너를 기동·재생성하거나 compose·볼륨·이미지·재시작 정책을 변경하지 않는다.
- 별도 물리 저장장치 백업은 사용자 결정으로 보류다. 원본 보관본과 활성 프로젝트가 같은 E 장치에 있으므로 물리 장애에 대비한 별도 매체 백업 완료로 표시하지 않는다.
- GitHub에는 이 검증 요약만 반영한다. 비공개 원본 로그·manifest·컨테이너 ID·환경 설정·키·DB·VHDX·원본 보관본은 업로드하지 않는다.
- 원본 근거는 비공개 `verification-result.json`, `path-switch.json`, `c-cleanup-verification.json`, `cleanup-final-result.json`이다. 공개 저장소 복제만으로 개인 환경용 이전 스크립트나 백업이 제공되지는 않는다.

## 후속 CI 보안 의존성 보완 — 실행 환경 미적용

이 문서 커밋의 CI에서 기존 API 이미지의 Brotli 1.2.0 및 Spring MVC 6.2.15에 대한 CRITICAL 보고로 이미지 게이트가 실패했다. 이전 파일 검증 실패와는 별개이며, 검사 severity·차단 조건을 완화하거나 CVE를 제외하지 않는다.

PR 소스의 Spring Boot를 4.1.2 BOM으로 맞춰 Spring Framework 7.0.10 등 호환되는 보안 패치 버전을 사용한다. 기존 Jackson 2 데이터 계약과 엄격한 JSON 파싱 설정을 명시적으로 유지하고, Flyway 자동 구성을 명시한다. 이전 Boot 3 전용 의존성 override는 제거했다. API·웹의 고정 Alpine 베이스에서 Brotli는 빌드 시 1.2.1-r0 이상으로 갱신한다. 기존 이미지 digest·실행 컨테이너는 변경하지 않는다.

analytics 이미지의 추가 검사에서 탐지된 Python `certifi`는 2026.10.18, Pillow는 13.0.0으로 갱신하고 런타임·CI SHA-256 잠금 파일을 다시 생성했다. 이 두 패키지 외 기존 잠금 버전은 유지했다.

웹 이미지에서 탐지된 Next.js 두 CRITICAL 권고에 따라 Next.js를 16.4.1로 갱신하고 npm 잠금 파일도 함께 갱신했다. UI 기능 변경이나 로컬 웹 서비스 기동은 수행하지 않는다.

이 변경은 PR 브랜치의 빌드 소스이며 로컬·공개 서비스에 적용하지 않았다. CI의 단위 테스트·이미지 검사 결과는 해당 커밋 실행을 기준으로 확인하며, 실제 서비스 배포·기동·DB 마이그레이션 검증과 구분한다. Jackson 2 호환 모듈은 Boot 4의 전환 지원 기능이므로 장기 Jackson 3 이전은 별도 검토 대상이다.
